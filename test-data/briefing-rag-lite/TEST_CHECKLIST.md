## C. 미팅 상세 브리핑 표시

- [ ] 📦 제품 자료에 01 진단기 제품자료가 보인다
- [ ] 📦 제품 자료에 02 카트 제품자료가 보인다 (견적 품목 제품)
- [ ] 📎 관련 자료에 03 납품계약서가 보인다
- [ ] 📎 관련 자료에 04 설치점검 문서가 보인다 (같은 고객사 다른 딜)
- [ ] RAG 검색 태그(검색 방식·상태)가 표시된다

## D. 검색 근거 내용

- [ ] 인용문에 `BLUE-731` 이 포함된 문장이 있다
- [ ] 인용문에 `220V` 관련 문장이 있다
- [ ] 인용문에 `90cm` 관련 문장이 있다
- [ ] 계약서 인용의 페이지 표시가 **2페이지** 다
- [ ] 대금 지급 조건(계약금 30% / 잔금 70%)이 브리핑 또는 인용에 반영된다

## E. 범위 필터

- [ ] 05 다른 고객사 문서가 📎 관련 자료에 **없다**
- [ ] 05 다른 고객사 문서가 검색 근거 인용에 **없다**
- [ ] 브리핑 본문에 무관 테스트의원 관련 내용이 섞이지 않는다

## F. 브리핑 생성 후 자료 추가 (재생성 필요 표시)

브리핑은 새로고침을 눌러야만 다시 만든다. 자료가 바뀌면 미팅 상세에 태그만 뜬다.

- [ ] 브리핑 생성 완료 후 06 추가자료를 현재 딜에 업로드, 처리 완료
- [ ] 워커 로그에 브리핑 실행이 새로 잡히지 않는다
- [ ] 미팅 상세를 열면 이전 브리핑 그대로이고 `반영되지 않은 내용이 있습니다` 태그가 보인다
- [ ] `새로고침` 을 누르면 `최신 자료 반영 중` 태그가 보인다
- [ ] 재생성 중에도 이전 브리핑이 그대로 보인다 (로딩 화면으로 덮이지 않는다)
- [ ] 재생성이 끝나면 06 추가자료가 📎 관련 자료에 나타나고 `반영되지 않은 내용이 있습니다` 태그가 사라진다
- [ ] (실패 시) `최신 자료로 다시 만들지 못했습니다` 안내와 함께 이전 브리핑이 남는다

- [ ] 권한 없는 계정의 검색 근거 인용에도 07 문서 내용이 **없다**
