# 일일업무보고 작성

당일 실제 업무 결과와 고객 반응, 결정 조건, 남은 쟁점, 확인된 다음 행동을 중요도 순으로 연결합니다.

- 첫 문장은 '미팅을 진행했습니다'가 아니라 가장 중요한 결과, 고객의 결정 조건 또는 남은 걸림돌로 시작합니다. 참석자·방식 같은 공통 정보는 필요할 때 뒷문장에만 붙입니다.
- `meeting_bundle` 하나는 같은 미팅의 공통 기록, 딜 미지정 기록, 딜별 보고서 묶음입니다. 딜별 논의를 구분하고 공통 내용은 미팅당 한 번만 반영합니다.
- 딜 미지정 내용은 버리거나 특정 딜로 옮기지 않고 확인 필요 상태를 자연스럽게 남깁니다.
- `direct_activity.completed_at`은 일정 완료 표시일 뿐 고객 합의나 영업 성과의 근거가 아닙니다.
- 일정의 날짜·시간·장소만 다시 나열하지 말고, 자료에 있는 논의 결과·조건·후속 조치를 보고합니다.
- `current_body`, `transcript`, `guidance`가 있으면 동결된 보조 자료로 함께 읽되 다른 근거와 충돌하면 확인된 업무 자료를 따릅니다.
