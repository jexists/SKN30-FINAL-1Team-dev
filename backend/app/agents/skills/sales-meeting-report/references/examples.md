# 합성 작성 예시

아래는 표현 기준을 설명하기 위해 만든 가상의 B2B 영업 메모와 보고서 문장이다. 실제 고객 기록이나 사용자 승인 골든 예시가 아니며, 고정 양식도 아니다.

## 1. 조건부 검토를 구매 확정으로 바꾸지 않기

입력 메모:

> 한빛유통 최 팀장. 재고관리 SaaS 30계정, 월 90만원 견적 전달. 부가세 별도. 최 팀장이 보안 검토 통과하면 10월부터 써볼 수는 있다고 함. 예산은 아직 승인 안 됨. 나는 반응이 나쁘지 않다고 느꼈음. 내일 내가 보안 체크리스트 보내기로.

보고서 문장:

한빛유통 최 팀장에게 재고관리 SaaS 30계정 기준 월 90만원, 부가세 별도 견적을 전달했다. 최 팀장은 보안 검토를 통과하면 10월부터 사용해 볼 수 있다고 했다. 다만 예산은 아직 승인되지 않은 상태다. 영업담당자는 반응이 나쁘지 않다고 느꼈다. 내일 영업담당자가 보안 체크리스트를 전달하기로 했다.

판단 기준: 사용 가능성에 붙은 보안 조건과 예산 미승인을 남긴다. 담당자의 인상을 고객의 구매 의사로 바꾸지 않고, 기준일이 없는 ‘내일’을 날짜로 확정하지 않는다.

## 2. 관찰·고객 발언·담당자 추정 구분하기

입력 메모:

> 물류센터 포장라인 PX-200 시연. 현장에서 20개 포장했고 그중 2개는 테이프가 들뜸. 운영담당자는 속도는 괜찮은데 이대로 도입은 어렵다고 했다. 나는 테이프를 바꾸면 나아질 수도 있다고 생각함. 고객 요청은 다른 테이프로 재시험. 재시험 날짜는 못 정함.

보고서 문장:

물류센터에서 PX-200으로 포장 시연을 진행했다. 포장한 20개 중 2개에서 테이프가 들뜨는 현상을 확인했다. 운영담당자는 속도는 괜찮지만 현재 상태로는 도입하기 어렵다고 말하며 다른 테이프로 재시험해 달라고 요청했다. 영업담당자는 테이프를 바꾸면 개선될 가능성이 있다고 보았다. 재시험 날짜는 정하지 못했다.

판단 기준: 관찰된 결함과 도입에 대한 부정적 발언을 남긴다. 담당자의 개선 추정을 해결 결과로 쓰거나 고객의 재시험 요청을 일정 합의로 바꾸지 않는다.

## 3. 딜 미지정 발언과 불명확한 원문 남기기

입력 메모:

> 사무가구 교체와 회의실 장비 건 같이 이야기함. ‘다음 주 안에 그거 견적 다시 주세요.’ 어느 건 얘기인지는 메모에서 모르겠음. 장비 모델 메모는 ‘VC-?0’으로 적혀 있어 정확히 못 읽겠음. 금액은 결정 안 했고, 배송만 먼저 잡아달라는 뜻은 아니라고 함.

보고서 문장:

사무가구 교체와 회의실 장비를 논의하는 중 다음 주 안에 견적을 다시 달라는 요청이 있었다. 다만 어느 딜의 견적을 뜻하는지는 확인되지 않았다. 장비 모델은 원문에 ‘VC-?0’으로 적혀 있으나 정확한 표기를 판독하기 어렵다. 금액은 결정되지 않았으며, 배송 일정을 먼저 잡아 달라는 취지는 아니라는 설명이 있었다.

판단 기준: 딜이 특정되지 않은 요청도 내용으로 남기되 어느 한 딜의 후속 약속으로 확정하지 않는다. 불명확한 모델 표기를 추정해서 고치거나 배송에 관한 부정을 삭제하지 않는다.

## 4. 대화 요약을 상급자용 판단 보고서로 바꾸기

입력 메모:

> 한빛유통 최 팀장. 재고관리 SaaS 30계정, 월 90만원 견적 전달. 부가세 별도. 최 팀장이 보안 검토 통과하면 10월부터 써볼 수는 있다고 함. 예산은 아직 승인 안 됨. 내일 내가 보안 체크리스트 보내기로.

일반 대화 요약체 — 사용하지 않음:

이번 미팅에서는 재고관리 SaaS 도입과 견적에 대해 논의했다. 고객에게 제품과 가격을 설명했으며 보안 검토와 예산에 대해서도 의견을 나눴다. 향후 보안 체크리스트를 전달하고 지속적으로 협의할 예정이다.

상급자 보고체:

도입 여부는 아직 확정되지 않았으며 보안 검토 통과가 선행조건이고 예산도 미승인 상태다. 최 팀장은 보안 검토를 통과하면 10월부터 30계정 사용을 검토할 수 있다고 밝혔다. 전달 견적은 월 90만원, 부가세 별도이며 영업담당자는 내일 보안 체크리스트를 전달하기로 했다.

권장 제목: `보안 검토 선행·예산 미승인`

판단 기준: 미팅을 했다는 사실보다 현재 도입 판단, 남은 조건, 고객이 밝힌 가능 범위, 다음 행동을 먼저 보이게 한다. ‘긍정적’, ‘지속 협의’ 같은 근거 없는 총평으로 결론을 대신하지 않는다.

## 5. 딜에 미치는 의미와 필요한 지원 밝히기

입력 메모:

> 새봄병원 장비 교체 건. 기술 검증은 통과. 기존 장비 지원은 12월 31일 종료. 고객은 11월 예산심의에 안건을 올리지 못하면 연내 교체가 어렵다고 함. 10월 15일까지 견적 요청. 본사 보안 담당자 동석이 필요해서 영업팀장에게 일정 조율을 요청함.

상급자 보고체:

기술 검증은 통과했지만 11월 예산심의 상정이 연내 교체 여부를 가르는 남은 조건이다. 고객은 안건을 올리지 못하면 연내 교체가 어렵다고 밝혔으며 기존 장비 지원은 12월 31일 종료된다. 고객 요청에 따라 10월 15일까지 견적을 전달해야 한다. 본사 보안 담당자 동석이 필요해 영업팀장의 일정 조율 지원이 요청된 상태다.

권장 제목: `기술 검증 통과·11월 예산심의 상정 필요`

판단 기준: 딜에 미치는 의미와 상급자 지원 필요를 입력에 있는 인과관계와 요청 범위 안에서만 쓴다. 단순한 걸림돌을 계약 실패로 확대하거나 모든 보고서에 승인·지원 요청을 만들어 넣지 않는다.
