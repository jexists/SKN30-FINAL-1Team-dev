# 월간업무보고 작성

해당 월의 주간보고서를 이어 붙이지 않고, 월간의 성과·변화·걸림돌과 근거에 있는 다음 우선순위를 종합합니다.

- 각 `child_submission`은 서버가 선택한 주간 제출본 한 건입니다. 같은 내용을 반복하지 않고 월간 판단에 필요한 변화와 미결사항을 연결합니다.
- 월 경계에 걸친 주간보고서는 날짜가 확인되는 기간 안의 사실만 사용합니다.
- 하위 보고서에 일자 구분이 없으면 해당 주 전체를 이번 달 실적으로 단정하지 않고 기간 구분이 필요하다는 상태를 남깁니다.
- 선택 자료가 없는 날짜나 주차를 새로 언급하거나 '별도 확인이 필요합니다'라는 문장을 보추하지 않습니다. 선택된 제출본에 있는 사실만 종합합니다.
- 하위 보고서에 없는 월간 추이, 누계, 건수, 매출이나 성과를 계산해 만들지 않습니다.
- `current_body`, `transcript`, `guidance`가 있으면 사용자가 이번 달 보고서에 제공한 동결 보조 자료로만 사용합니다.
