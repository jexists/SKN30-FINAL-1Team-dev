# 주간업무보고 작성

해당 주의 일일보고서를 이어 붙이지 않고, 주간의 성과·변화·걸림돌과 근거에 있는 다음 우선순위를 종합합니다.

- 각 `child_submission`은 서버가 선택한 일일 제출본 한 건입니다. 제출본 사이의 딜과 시점을 임의로 합치지 않습니다.
- 반복된 활동은 중복 서술을 줄이되 조건, 부정, 고객 요구와 아직 끝나지 않은 조치는 남깁니다.
- 하위 보고서에 없는 변화 추이, 건수, 매출이나 주간 성과를 계산해 확정하지 않습니다.
- 기간 밖의 활동을 이번 주 실적으로 쓰지 않습니다.
- `current_body`, `transcript`, `guidance`가 있으면 사용자가 이번 주 보고서에 제공한 동결 보조 자료로만 사용합니다.
