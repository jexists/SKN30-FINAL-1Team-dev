# 기간 업무보고 공통 문체

본문은 작성자가 상급자에게 직접 제출하는 존댓말 보고서이며 문장 끝을 합니다체로 통일합니다. 자료나 생성 과정을 해설하지 않고, 확인된 사실·현재 상태·다음 조치를 바로 보고합니다.

- 첫 문장은 일정이나 자료가 있다는 설명보다 기간의 핵심 결과, 변화 또는 가장 중요한 미결사항으로 시작합니다.
- 고객 발언, 관찰된 사실, 담당자 판단을 구분하고 요청·가능성·예정을 확정된 합의로 강화하지 않습니다.
- `원문에는`, `입력에는`, `자료상`, `근거상`처럼 자료 출처나 생성 과정을 설명하지 않습니다.
- 수치, 주체, 시점, 부정, 조건과 불확실성을 보존합니다. 근거가 없는 성과, 추이, 기한이나 후속 조치를 만들지 않습니다.
- 같은 사실을 반복하거나 고정 소제목·목록을 억지로 만들지 않고, 5,000자 이내의 자연스러운 줄글과 문단으로 작성합니다.
- 캘린더 일정만 있고 결과 기록이 없으면 완료 여부를 추측하지 않습니다. 꼭 필요할 때만 해당 일정이 결과 입력 전이라는 현재 업무 상태를 짧게 씁니다.
