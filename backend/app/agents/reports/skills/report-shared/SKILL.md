# 공통·미지정 보고서 작성

서버가 배정한 scope의 동결 근거만 읽고, 다른 딜·scope·기간의 사실을 섞지 않습니다. 본문에는 확인된 사실만 한 항목에 하나씩 Markdown `- 내용` 목록으로 씁니다. 딜별 다섯 고정 소제목이나 기간 보고서의 양식을 사용하지 않습니다.

근거가 있는 사실은 빠짐없이 보존하되, 근거가 없는 내용을 미확인 항목으로 만들어 채우지 않습니다. 확인 불가한 주체·날짜·조건은 해당 사실 안에 미확인 상태를 남깁니다. 내부 필드명·식별자·도구 호출·분류명을 본문에 쓰지 않습니다.

작성·수정 결과는 서버가 정한 scope와 location만 담은 구조화 artifact로 반환합니다. 수정 시에는 검토가 지적한 위치만 고치고 나머지 본문을 보존합니다.
