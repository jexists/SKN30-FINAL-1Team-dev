# 일일업무보고 작성

오늘 무엇을 했고 어떤 결과와 다음 업무가 남았는지 보고합니다. 공통 작성 기준을 적용하고, 미팅 전체 내용을 복사하지 않습니다.

## 작성 순서

**오늘 한 일 → 거래처별 결과 → 미완료·문제 → 다음 업무** 순으로 씁니다.

1. **오늘 한 일:** 실제 수행한 업무를 짧게 묶어 밝힙니다. 방문·전화·온라인·이메일은 활동별 근거에 따라 구분하고, 방식이 없으면 미확인으로 표시합니다. 일정만 있으면 예정 또는 완료 여부 미확인으로 구분합니다.
2. **거래처별 결과:** 거래처 안에서도 딜별 제안·검증·고객 결정·조건 변화를 구분해 요약합니다. 발언 전부 대신 확인된 결과와 후속 조치에 필요한 맥락만 남깁니다. 결과가 없으면 결과 미확인으로 밝힙니다.
3. **미완료·문제:** 남은 요청, 보류 조건, 지연·문제와 확인된 영향을 씁니다. 근거가 없는 지연 원인이나 고객 거절을 만들지 않습니다.
4. **다음 업무:** 이어서 할 일을 요청·제안·합의 상태와 함께 정리합니다. 담당자·기한·완료 기준을 쓰고 빠진 항목은 각각 미지정·미확인으로 밝힙니다. 다음 업무가 확인되지 않으면 약속을 새로 만들지 않습니다.

## 집계 기준

- 같은 미팅의 공통 기록, 딜별 기록, 미지정 기록은 하나의 미팅으로 읽습니다. 공통 내용은 한 번만 반영하고, 미지정 요청은 버리거나 특정 딜로 옮기지 않습니다.
- 동일한 활동의 여러 딜 본문을 별도 미팅이나 계약으로 중복 집계하지 않습니다. 일정 완료 표시만으로 고객 합의나 영업 성과가 생겼다고 보지 않습니다.
- 전날의 요청을 오늘 이행했다면 두 시점을 구분합니다. 이전 활동이나 이후 계획을 오늘 실적으로 포함하지 않습니다.
- 선택된 당일 미팅 제출 BODY와 검증된 활동·첨부를 사용합니다. 작성 지시의 명시적 정정은 해당 사실에만 반영합니다.
