# SalesLuv AI 업무 여정 데모 영상 설계

## 목표

60초 이내의 QHD MP4 영상으로, 고객·문서·보고 업무가 흩어지는 문제를 SalesLuv의 연결된 AI 업무 흐름으로 해결하는 모습을 설명한다. 음성 내레이션 없이 한국어 자막과 배경음악으로 전달한다.

## 대상과 핵심 메시지

- 대상: 최종 발표·평가 시 제품 가치를 빠르게 파악해야 하는 시청자
- 문제: 고객 정보, 제품 자료, 미팅 준비와 보고가 여러 도구에 분산되어 영업 맥락이 끊기고 기록이 중복된다.
- 메시지: SalesLuv는 고객 등록부터 문서 요약, 미팅 브리핑, 보고서 초안까지를 연결하고, AI 결과는 사용자가 검토한 뒤 업무에 반영한다.

## 영상 구조

| 구간 | 목표 시간 | 촬영 화면 | 하단 자막 | 강조 요소 |
| --- | ---: | --- | --- | --- |
| 프로젝트 동기 | 0–10초 | 제목 카드와 분산 업무 키워드 | 고객 정보와 영업 기록이 여러 도구에 흩어져 있습니다. | `고객`, `문서`, `보고` 키워드 |
| 해결 문제 | 10–18초 | 연결된 업무 흐름 오버레이 | SalesLuv는 고객 맥락을 연결하고, AI 초안을 사람의 검토로 업무에 반영합니다. | 고객 → 요약 → 브리핑 → 보고서 |
| 고객 등록 | 18–30초 | 고객 목록과 등록 폼 | 신규 고객 정보는 팀이 함께 쓰는 영업 맥락으로 저장됩니다. | 필수 고객 정보 입력과 저장 동작 |
| AI 문서 요약 | 30–41초 | 자료실 문서와 요약 패널 | AI가 핵심 제품 정보와 영업 포인트를 빠르게 정리합니다. | 원문 문서와 요약 결과 |
| AI 브리핑 | 41–51초 | 미팅 브리핑 화면 | 미팅 전에는 고객 이력과 자료를 바탕으로 준비할 내용을 제안합니다. | 미팅 목표, 확인 질문, 과거 이력 |
| AI 보고서 | 51–59초 | AI 보고서 초안과 검토 영역 | 미팅 후에는 근거 기반 초안을 검토해 다음 업무로 연결합니다. | AI 초안, 검토·수정, 확정 전 상태 |

## 시각·편집 설계

- 캔버스: 2560×1440(QHD), MP4(H.264), 30fps.
- 화면 전환: 짧은 컷 전환과 부드러운 줌·패닝으로 전체 길이를 60초 미만으로 유지한다. 실제 처리 대기 시간은 제거하거나 2–4배속 처리한다.
- 강조: 비강조 영역을 어두운 반투명 오버레이로 덮고, 강조 대상에는 청록색 바운딩 박스와 번호 라벨을 부착한다. 라벨은 상자 바깥의 비어 있는 영역에 배치해 핵심 UI를 가리지 않는다.
- 자막: 영상 중앙 하단 안전 영역에 1~2줄 한국어 자막을 배치한다. 고대비 반투명 배경을 사용하며 강조 라벨과 겹치지 않게 한다.
- 사운드: 권리 문제가 없는 잔잔한 배경음악만 사용하고 음성 내레이션은 넣지 않는다.

## 녹화 원칙

- 실제 데모 데이터만 사용하고, 비밀값·개인정보·원본 고객 데이터는 화면에 노출하지 않는다.
- 기존 작업 트리의 사용자 변경은 수정하지 않는다.
- Playwright로 실제 브라우저 동작을 녹화한다. 라우트·로그인·데모 데이터가 준비되지 않은 경우에는 먼저 안전하게 상태를 점검하고, 필요한 데모 데이터의 생성 또는 변경은 별도 확인을 받는다.
- 최종 결과물은 `output/playwright/` 아래에 원본 캡처와 편집본을 구분해 저장한다.

## 완료 기준

1. 60초 미만의 MP4 파일이 생성된다.
2. 해상도는 2560×1440 이상이다.
3. 프로젝트 동기, 해결 문제, 실제 데모 구현의 세 구성이 시간 순서대로 포함된다.
4. 고객 등록, AI 문서 요약, AI 브리핑, AI 보고서의 실제 화면이 포함된다.
5. 각 핵심 화면에 spotlight, 바운딩 박스, 설명 라벨이 있고 모든 구간에 한국어 상황 자막이 있다.
6. 재생·해상도·길이를 메타데이터로 검증한다.
