# OCR API 1장 실측 결과

## 테스트 조건

- 테스트 일자: 2026-08-06
- 입력: 한국어 손글씨 미팅 노트 JPG 1장(4,032 × 3,024px, 2.6MB)
- 초기 프롬프트로 GPT-5.6 Luna와 GPT-5 nano를 각 1회 호출
- 추론·보완 금지 프롬프트로 GPT-5.6 Luna를 추가 1회 호출
- GPT-5.6 Luna: `detail=original`, `reasoning.effort=none`
- GPT-5 nano: `detail=high`, `reasoning.effort=minimal`
- 환율: 1 USD = 1,400원
- 원문 출력과 정답지는 개인정보·이미지 메타데이터 검토 전까지 팀 공유 저장소에 비공개로 보관

- GPT-5 nano는 다수의 문장을 잘못 읽었고 후반부 항목을 누락해 손글씨 OCR 결과로 사용하기 어려웠다.
- 정확도는 손글씨 이미지 1장 기준이므로 모델 전체 성능을 의미하지 않는다.

## 건당 처리시간

| 구분 | 현재 기준 시간 | 산정 기준 |
|---|---:|---|
| GPT-5.6 Luna·초기 | 11.525초 | API 1회 실측값 |
| GPT-5.6 Luna·추론 금지 | 7.570초 | API 1회 실측값 |
| GPT-5 nano·초기 | 5.092초 | API 1회 실측값 |
| RunPod OCR | 미실측 | 모델 확정 및 RunPod 배포 후 측정 |

- API 시간은 표본 1건이므로 반복 측정 전까지 확정 평균이 아니다.
- Active 워커를 2대로 늘려도 건당 처리시간은 같고, 동시에 처리할 수 있는 요청 수가 늘어난다.

## RunPod 비용 기준

- 대상: Serverless 24GB GPU 그룹(L4/A5000/RTX 3090/MIG 24GB)
- 현재 공개 Flex 단가: $0.69/시간, 초 단위 과금
- Flex 가정: 명함 90건 × 0.5초 + 손글씨 600장 × 1초 + 초기화·모델 로딩·idle 20초 = 사용자당 월 665초
- Active 1대 기준: 기존 비교 기준인 $0.468/시간 × 720시간 × 1,400원 = 월 471,744원
- Active 2대 기준: 월 471,744원 × 2대 = 월 943,488원
- 워커 추가는 동일한 OCR 모델을 실행하는 GPU 인스턴스를 한 대 더 상시 가동해 요청을 나눠 처리하는 것이다. 단일 요청이 두 배 빨라지는 것이 아니라 동시 처리 용량이 늘어나며, Active 비용은 워커 수에 비례한다.
- 현재 RunPod 문서는 Active 할인 단가를 공개 고정값이 아닌 별도 문의 대상으로 안내하므로, 실제 계정에 표시되는 단가는 배포 전에 다시 확인한다.
- RunPod OCR 모델의 정확도·실행시간·GPU 메모리는 아직 실측하지 않았다.

## 현재 결론

- 손글씨 OCR 비교군에서 GPT-5 nano는 제외한다.
- GPT-5.6 Luna를 현재 API 기준 모델로 유지하지만, 프롬프트만으로 문맥 추론을 충분히 막지 못했다.
- RunPod는 비용상 유력하지만 정확도와 실제 billed worker time을 측정하기 전에는 최종 선택하지 않는다.
- Active 1대는 현재 기준 약 145명부터 Luna 단순 환산 비용보다 저렴하다. 이는 한 대가 해당 요청량을 처리할 수 있다는 전제다.
- 명함 이미지 1장을 별도로 실측한 후 명함 90건과 손글씨 600장의 월간 혼합 비용을 다시 계산한다.
- RunPod 계정이 준비되면 동일 이미지로 정확도, 실행시간, 콜드스타트, 동시 처리량을 실측한다.
