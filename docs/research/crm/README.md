## 분류 원칙

- 제공사의 기능·가격·화면과 공식 근거는 `competitor-research/`에 둡니다.
- 조사 결과를 바탕으로 SalesLuv에 무엇을 넣을지는 `product-decisions/`에만 기록합니다.
- 앱 리뷰처럼 사용자 의견을 집계한 자료는 `user-feedback/`에 둡니다.
- 시장 규모와 도메인 선택 근거는 `market/`에 둡니다.
- 비교 보고서 이름에는 조사한 서비스 범위를 드러내 동일한 “CRM 비교” 문서끼리도 구분합니다.
