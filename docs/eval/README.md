## 03 미팅 브리핑

계약관리 Agent 가 만드는 미팅 브리핑을 **누적 깊이**(미팅 1·3·5·10·30회)로 평가했다.
케이스 30건(체인 6 × 깊이 5), 전체 평균 89.8%. 입력 보고서 180건은 실제 분량(딜 본문 800자 이상). 검사 2,545건 통과.

- `SalesLuv_미팅브리핑_평가.pptx` — 발표용 5장 (데이터셋 · 정답 계산 · 메트릭 · 타당성 · 결과)
- `SETUP.md` · `재현_설정_가이드.pdf` — **빈 계정에서 처음부터 돌리는 절차.** DB 없이 LLM 설정만으로 실행된다. 문서대로 빈 폴더에서 다시 돌려 확인한 결과도 함께 적었다
- `결과/미팅브리핑_평가결과.pdf` · `결과/결과요약.md` — 깊이별·체인별 점수와 발견된 실패
- `결과/브리핑_결과확인.html` — 케이스별로 원문 → 실제 브리핑 → 골든 정답을 나란히 보고 잘됨/못됨으로 거르는 확인용 화면
- `데이터셋/timelines/` — 체인 6개. 회사당 보고서 30건과 주제 타임라인
- `데이터셋/cases/` — 깊이별로 잘라 만든 입력·정답 30쌍
- `결과/SUMMARY.json` · `결과/생성출력/` · `결과/judged/` — 집계, 실제 생성물, 채점 기록
- `스크립트/` — 보고서 확장 · 케이스 생성 · 실행 · 채점 · 집계 · 검사 6개
- `결과/v15_비교/` — 같은 골든셋을 최신 브리핑(v15, develop `b431b49c`)으로 다시 돌린 결과
  - `브리핑_v13_v15_비교.html` — 깊이·항목·고객사·케이스별 비교와 변화 원인 분석. 결론은 **횡보**(89.8% → 86.6%, RAG 호출 여부가 같은 21건은 +0.6%p)
  - `SUMMARY.json` · `생성출력/` · `judged/` — v15 집계, 실제 생성물, 채점 기록
