## 2. 문제 정의

- `[VERIFIED]` 핵심 문제: "B2B 영업의 핵심 자산인 고객 맥락과 영업 노하우는 담당자 개인에게 암묵지로 축적되지만 조직 자산으로 남지 않아, 이직·인수인계 시 관계와 노하우가 함께 소실된다." — P2 2장, PPT#3 6장
- `[VERIFIED]` GS의 5가지 문제 (GS 7장 일러스트, 14장 카드):
  1. 영업정보 분산: 고객·영업·계약·매출 정보가 따로 관리됨
  2. 영업흐름 단절: 리드 → 미팅 → 제안 → 견적 → 계약 → 매출이 연결되지 않음
  3. 판단 공백: 진행 상황과 매출 예측이 불명확함
  4. 인수인계 맥락 소실: 담당자가 바뀌면 고객 관계가 끊김 (GS 14장에서 강조색)
  5. 범용 CRM의 한계: 고객정보만으로는 B2B 영업을 관리하기 어려움
- `[VERIFIED]` 기획서의 조직 영향: 정보 분산 → 맥락 단절·재파악 비용 / 보고 중복 → 영업 시간 감소 / 다음 행동 부재 → 기회 손실 / 팀 현황 불투명 → 코칭·의사결정 지연 — P2 2장
- `[VERIFIED]` 방향 전환: 기획발표에서는 의료기기 영업 CRM(Key Doctor 성향)을 타깃으로 잡았고, 중간발표부터 국내 B2B 영업팀으로 넓혔습니다. — PPT#1 4·5장 → PPT#3 6·8장

## 3. 문제의 근거

- `[VERIFIED]` 국내 CRM 시장: 2025년 약 2조 5,084억원 → 2026년 약 2조 7,500억원 → 2033년 약 5조 4,595억원, 2026–2033 CAGR 10.3% (Grand View Research, 2026 업데이트) — R1, GS 8장
- `[VERIFIED]` 국내 SaaS 시장: 2025년 약 2조 1,295억원 → 2029년 약 4조 164억원, CAGR 17.1% (KISDI 2026, 원자료 Gartner 2025). CRM과 SaaS는 시장 정의가 달라 합산하지 않음 — R1, GS 8장
- `[VERIFIED]` 원화 환산 기준: 2026-09-15 USD/KRW 1,347.8원 — R1
- `[VERIFIED]` 영업 CRM만 따로 집계한 공개 시장 규모는 확인되지 않음 — R1, GS 9장
- `[VERIFIED]` 경쟁 현실: AI 미팅 준비·요약·후속조치 기능은 이미 있음 (HubSpot Breeze, 핑거세일즈 AI CRM, 세일즈인사이트 CRM, 인접 대체재 세일즈랩). 초기 ICP는 문서·견적·계약·납품이 복잡한 B2B 영업팀. 차별화 조건은 근거 검색 + 영업 데이터 연결 + 담당자 승인 — R1, GS 9장
- `[VERIFIED]` 문제의 출발점 (사용자 확인 2026-09-17): 문제 정의는 **영업사원인 PM(천성배)의 현장 경험**에서 나왔습니다. GS 14장 선정 기준의 "고객 인터뷰·파일럿 테스트가 가능함"도 PM이 영업사원이라 가능하다는 뜻입니다.
- 설문 등 정량 근거는 없으므로 슬라이드에서는 수치 없이 "현장 경험 기반"으로 표현합니다.
- `[사용 안 함]` PPT#1·#2의 의료기기 시장 수치(기업 6,661개, 종사자 20,036명 등): 타깃이 B2B로 바뀌었고 출처 표기도 자료마다 다름
- `[사용 안 함]` Salesforce 앱 리뷰 집계(18,474건, 저평점 22.8%): 우리 문제 정의와 직접 연결이 약함

## 4. 기존 방식의 한계

- `[VERIFIED]` 메시지: "기존 서비스가 영업 데이터를 '관리'한다면, SalesLuv는 데이터를 '활용 가능한 다음 행동'으로 전환합니다." — GS 10장
- `[VERIFIED]` 차별화 포인트 3개: AI 자동화(미팅 기록 → 보고서 초안·다음 행동) / 근거 기반 추천(고객 히스토리·딜 단계·일정·계약·내부 문서 연결) / Human-in-the-loop(AI 제안 → 담당자 검토·승인 → 업무 반영) — GS 10장
- `[VERIFIED]` 기획서 비교: 일반 CRM(저장·조회) / 그룹웨어(공유·결재) / SalesLuv(기록을 다음 실행으로 연결, 사람 승인 후 변경) — P2 6장
- `[VERIFIED]` **GS 10장 비교표는 시장조사 기준으로 수정 (사용자 결정 2026-09-17)**
  - GS 10장은 세일즈맵·핑거세일즈·세일즈인사이트의 "AI 자동화"를 모두 ×로 표시했습니다.
  - 하지만 R1과 GS 9장에 따르면 핑거세일즈 AI CRM에는 미팅 요약·액션아이템·다음 행동 추천·사용자 확인 후 반영 기능이 있고, `docs/research/crm/competitor-research/`에는 세일즈맵 AI(sailo) 화면 캡처가 있습니다.
  - 수정 방향: 경쟁사의 AI 보유를 인정하고, 차이를 "근거 연결 + 담당자 승인 + 승인 결과가 다음 추천·브리핑으로 되돌아오는 순환"으로 표현합니다.
  - AI 관련 행 판정 (R1, `docs/research/crm/competitor-research/four-provider-features/evidence.json`)
    - 세일즈맵: Sailo AI 자연어 조회 화면 확인, CRM 쓰기는 미검증 → △
    - 핑거세일즈: 미팅 요약·액션아이템·다음 행동 추천·사용자 확인 후 반영 → ●
    - 세일즈인사이트: 공개 기능에서 AI 미확인 → "–"
    - "승인 결과가 다음 미팅 추천·근거 브리핑으로 순환": 경쟁 3사 공개 자료에서 미확인 → "–"
  - "–"는 "없음"이 아니라 "공개 자료에서 확인 안 됨"으로 각주 표기
  - AI 외 7개 행은 조사 기준 자료가 없어 GS 10장 판정을 그대로 두고 출처를 GS 10장으로 표기
- `[제외]` GS 11–13장 핑거세일즈 화면 캡처: 사용자 의견에 따라 넣지 않음
