# SalesLuv 최종 발표 슬라이드 구성안

사실 근거는 [presentation_research.md](presentation_research.md)의 같은 번호 섹션을 따릅니다.

## 전체 설계

### 스토리라인
1. **청중이 처음 알아야 할 것**: 영업 맥락은 담당자 개인에게 남고, 담당자가 바뀌면 끊긴다.
2. **문제와 배경**: 정보 분산 → 흐름 단절 → 판단 공백 → 인수인계 맥락 소실. 시장은 커지지만 경쟁사도 이미 AI를 갖고 있다.
3. **핵심 인사이트**: 차이는 AI 유무가 아니라, 근거를 연결하고 사람이 승인한 결과가 다음 행동으로 되돌아오는 구조다.
4. **근거**: 실제 구현된 에이전트 5종과 작업 큐 구조, Agent별 평가 결과.
5. **청중이 기억할 메시지**: SalesLuv는 담당자의 머릿속을 조직의 기록(11개 영역)으로 남긴다.

### 구성 규칙
- 분량: 표지·목차 2장 + 섹션 디바이더 3장 + **본문 24장** + Q&A 1장 + 부록 2장 = 32장

## Slide 05 — 선정근거: 5가지 문제 (GS 7 + 14)

**목적** 문제를 흐름으로 보여주고, 그 끝이 "인수인계 맥락 소실"임을 각인시킨다.

**핵심 메시지** 흩어진 정보가 흐름과 판단을 끊고, 결국 담당자가 바뀌면 맥락이 사라진다.

**헤드라인** 영업 맥락은 담당자가 바뀌는 순간 끊긴다
**부제** 정보 분산에서 시작된 문제가 인수인계 맥락 소실로 이어진다

**들어갈 내용**
- 상단 가로 프로세스 5단계 (번호 원 + 제목 + 한 줄), 4번 강조
  1. 영업정보 분산 — 고객·영업·계약·매출 정보가 따로 관리됨
  2. 영업흐름 단절 — 리드→미팅→제안→견적→계약→매출이 연결되지 않음
  3. 판단 공백 — 진행 상황과 매출 예측이 불명확함
  4. **인수인계 맥락 소실 — 담당자가 바뀌면 고객 관계가 끊김**
  5. 범용 CRM의 한계 — 고객정보만으로는 B2B 영업 관리가 어려움
- 하단 좌: GPT 일러스트 1장 (인수인계 장면)
- 하단 우: "주제 선정 기준" 카드 (GS 14장)
  - 대상 고객을 기업 영업팀으로 좁힐 수 있음

  - 국내 계약·견적·업무 도구와 연계 가능
  - 카드 하단 태그: "문제 정의 출발점: 영업사원 PM의 현장 경험"

## Slide 06 — 시장현황 (GS 8 + 9)

**목적** 문제를 풀 가치가 있는 시장인지, 어떤 조건으로 들어가야 하는지 근거를 준다.

**핵심 메시지** CRM 시장은 성장하고 있지만, 영업 CRM만의 공개 통계는 없다. 진입 조건은 기능 나열이 아니라 근거 검색 + 영업 데이터 연결 + 담당자 승인이다.

**헤드라인** 시장은 성장 중, 진입 조건은 맥락과 근거의 연결
**부제** 영업 CRM 단독 시장규모는 공개되지 않아, 성장성과 진입 조건을 함께 본다

**들어갈 내용**
- 좌 (Data Card): 국내 CRM 시장 세로 막대 차트
  - 2025 2조 5,084억 / 2026 2조 7,500억 / 2033 5조 4,595억
  - 라벨 "CAGR 10.3% (2026–2033)"
  - 아래 KPI 타일: 국내 SaaS 2조 1,295억(2025) → 4조 164억(2029), CAGR 17.1%
  - 각주: "시장 정의가 달라 CRM과 SaaS는 합산하지 않음"
- 우: 3단 세로 흐름
  - 경쟁 현실: AI 미팅 준비·요약·후속조치 기능이 이미 존재
  - 초기 ICP: 문서·견적·계약·납품이 복잡한 B2B 영업팀
  - 차별화 조건: 근거 검색 + 영업 데이터 연결 + 담당자 승인
