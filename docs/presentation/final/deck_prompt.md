## 0. 역할

너는 SKN30 1TEAM(팀명 **CassTerra**)의 최종 발표 PPT를 **디자인부터 다시** 만드는 담당자다.
내용(사실·수치·스토리)은 아래에 확정되어 있으니 **다시 조사하지 말고**, 레이아웃과 시각 표현만 새로 설계한다.
확정된 사실을 바꾸거나, 여기 없는 기능·수치·성과를 추가하지 않는다. 애매하면 **추측하지 말고 질문**한다.

## 2. 절대 규칙

1. **사실 정확성 > 발표 완성도.** 코드에 없는 기능을 있다고 쓰지 않는다.
2. 모든 수치에 출처를 붙인다. 아래 3장에 적힌 수치만 쓴다.
3. **사용 금지 수치**: 기존 작업본에 있던 "업무효율 40%", "30%/60%/30%" 등 근거 없는 예시 값 — 절대 쓰지 않는다.
4. 기대효과의 정량 수치는 **파일럿 목표(가설)**이며 실측값이 아니다 → `[수치 입력 예정]` 자리로 둔다.
5. **보안**: AWS 계정 ID, Elastic IP, EC2 인스턴스 ID, 보안그룹 ID, CloudFront 배포 ID·도메인, S3 버킷명, IAM Role ARN을 슬라이드·캡처 어디에도 넣지 않는다. `.env`·API 키·토큰도 마찬가지.
6. 실제 고객·영업 데이터, 개인정보가 담긴 캡처를 넣지 않는다. 평가용 데이터는 모두 합성 데이터임을 표기한다.

## 4. 문서와 코드가 어긋나는 지점 (이미 정리됨 — 되돌리지 말 것)

- **일정관리 에이전트는 캘린더 연동을 하지 않는다.** 저장된 추천의 유효성만 재판단한다(유효/재생성/무시)
- **다음 미팅을 제안하는 주체는 계약관리**다(일정관리 아님)
- **보고서 확정 시 딜이 자동 갱신되지 않는다.** 확정은 RAG 적재와 다음 미팅 추천 트리거를 부른다
- **전역 LLM Supervisor는 없다.** 에이전트 연결은 agent_run 큐 + 코드 dispatch + API 트리거로 이뤄진다
- **미구현**: 고객 감정 분석, 계약 갱신·만료 트리거, 외부 캘린더 연동, 코칭 대시보드, 키워드 추출, 딜 타임라인 화면
- **STT는 파일 첨부만** 지원한다(녹음 UI 없음)
- 매출 분석 화면은 AI 기능이 아니다
- 검색은 키워드 + pgvector 코사인을 RRF로 병합하는 하이브리드다(벡터 임베딩 운영 중)

## 6. 제작·검수 절차
