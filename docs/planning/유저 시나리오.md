# CRM 유저 시나리오 / 화면설계서

---

## 1. 로그인 / 회원가입

### 화면 목적

서비스 이용을 위한 로그인 및 회원가입을 제공한다.

### 화면 구성

* 화면을 처음 진입하면 서비스 설명 영역과 로그인 화면이 함께 노출된다.
* 좌측: 서비스 설명
* 우측: 로그인 화면

### 사용자 시나리오

1. 사용자가 서비스에 접속한다.
2. 서비스 설명과 로그인 화면을 확인한다.
3. 기존 사용자는 이메일과 비밀번호를 입력하여 로그인한다.
4. 회원가입이 필요한 경우 회원가입을 신청한다.
5. 회원가입 신청 시 입력한 이메일로 안내 메일이 전송된다.
6. 사용자는 이메일을 확인하여 비밀번호 변경 안내를 확인한다.
7. 이메일에 안내된 방법에 따라 비밀번호를 변경한다.
8. 변경한 비밀번호로 로그인한다.

# 2. 대시보드

### 화면 목적

사용자가 업무 시작 시 회사 및 팀의 주요 업무 현황과 일정을 한눈에 확인할 수 있도록 한다.

### 주요 기능

#### 회사 공지 / 팀장 지시사항

* 회사 공지를 확인할 수 있다.
* 팀장 지시사항을 확인할 수 있다.
* 공지 또는 지시사항을 클릭하면 상세 내용을 확인할 수 있다.

#### 주요 업무 현황

다음과 같은 간단한 정보를 확인할 수 있다.

* 오늘 방문 거래처
* CS 대응 요청
* 계약 갱신
* 매출 목표

#### CS 대응 요청

* CS 대응 요청 건수를 확인할 수 있다.
* 클릭하면 CS 대응 요청 리스트를 확인할 수 있다.

#### 계약 갱신

* 계약 갱신 예정 건수를 확인할 수 있다.
* 클릭하면 계약 갱신 예정 리스트를 확인할 수 있다.

#### 매출 목표

* 현재 매출 목표에 대한 간단한 정보를 확인할 수 있다.
* 매출 목표를 클릭하면 **매출분석 화면**으로 이동한다.

#### 주간 업무 / 일정

* 주간 업무를 확인할 수 있다.
* 일정을 추가할 수 있다.
* 등록된 일정을 확인할 수 있다.
* 일정을 클릭하면 일정 상세 내용을 확인할 수 있다.

  * 미팅 정보
  * AI 브리핑

#### 일정 종료 후

* 일정이 종료되면 업무보고서 작성으로 이어진다.
* 사용자는 해당 일정에 대한 보고서를 작성할 수 있다.

# 3. 고객 현황

### 화면 목적

등록된 고객 및 고객사의 정보를 조회하고 관리한다.

### 주요 기능

#### 고객 등록

고객 정보를 다음과 같은 방법으로 등록할 수 있다.

* 명함 이미지 등록
* 엑셀을 통한 다량 등록
* 수동 등록

#### 리스트 설정

* 사용자가 보고 싶은 컬럼을 선택할 수 있다.
* 컬럼의 순서를 변경할 수 있다.

#### 엑셀 내보내기

* 리스트에서 원하는 고객을 선택할 수 있다.
* 선택한 리스트만 엑셀 파일로 내보낼 수 있다.

#### 검색

* 고객 정보를 검색할 수 있다.

# 8. 고객 불만 등록

4. 하나의 딜을 선택한다.

6. 등록한다.

### 입력 정보

* 딜
* 제목
* 상태
* 발생 날짜
* 긴급도
* 내용

# 12. 업무보고

### 화면 목적

사용자가 작성한 업무보고서를 기간 및 상태별로 조회하고 관리한다.

### 조회 유형

* 전체
* 업무보고
* 일일 업무
* 주간 업무
* 월간 업무

### 캘린더

* 일주일 단위의 주간 달력을 확인할 수 있다.
* 주간 달력은 **일요일~토요일** 기준으로 표시한다.
* `달력 더보기`를 클릭하면 월간 달력을 확인할 수 있다.
* 달력에서 작성된 보고서가 있는지 확인할 수 있다.

### 보고서 리스트

* 작성된 보고서 리스트를 확인할 수 있다.
* 상태값으로 필터링할 수 있다.
* 기간으로 필터링할 수 있다.

### 상태값

* 작성중
* 검토대기
* 확정
* 반려

# 13. 업무보고서 작성

### 화면 목적

미팅 및 영업 활동 내용을 기반으로 업무보고서를 작성한다.

### 미팅 정보

* 해당 일정의 미팅 정보를 확인할 수 있다.
* 회사와 연결된 영업 리스트를 확인할 수 있다.
* 현재 영업 현황을 체크할 수 있다.

### 첨부자료

다음 자료를 첨부할 수 있다.

* PDF
* 음성
* 이미지

### 보고서 작성

* 미팅 내용을 직접 작성할 수 있다.
* `AI 작성하기` 버튼을 클릭하면 AI가 미팅 내용을 기반으로 보고서를 작성한다.
* AI가 작성한 내용을 사용자가 직접 수정할 수 있다.

### AI 작성 결과 확인

화면 좌측에서 다음 내용을 확인할 수 있다.

* 사용자가 입력한 내용
* AI 원본

사용자는 AI가 작성한 내용을 확인한 후 필요한 부분을 수정하여 최종 보고서로 작성한다.

# 21. 자료실 등록

### 화면 목적

업무 자료를 업로드하고 관련된 상품 또는 딜과 연결한다.

### 입력 정보

* 파일 선택
* 연결 대상
* 메모

### 연결 대상

자료를 다음 대상과 연결할 수 있다.

* 상품
* 딜

### 상품 연결

* 연결 대상이 상품인 경우 상품을 선택하여 연결한다.

### 딜 연결

* 연결 대상이 딜인 경우 딜을 선택하여 연결한다.

### 메모

* 해당 자료에 대한 메모를 작성할 수 있다.

### AI 에이전트 처리

자료가 딜과 연결되는 경우 AI 에이전트가 업로드된 자료를 확인한다.

1. 사용자가 자료를 업로드한다.
2. 연결 대상을 딜로 선택한다.
3. 연결할 딜을 선택한다.
4. AI 에이전트가 자료 내용을 확인한다.
5. AI 에이전트가 자료에서 확인한 딜 관련 정보를 사용자에게 제공한다.
6. 사용자가 AI가 확인한 정보를 검토한다.
7. 사용자가 확인 및 승인한다.
8. 승인된 정보가 해당 딜에 저장된다.

# 22. 알림

### 화면 목적

사용자에게 발생한 주요 알림을 확인한다.

### 주요 기능

알림을 다음 기준으로 확인할 수 있다.

* 전체
* 읽지 않음

사용자는 알림을 클릭하여 관련된 화면 또는 정보를 확인할 수 있다.

# 23. 마이페이지

### 화면 목적

사용자의 서비스 이용 관련 정보를 확인하고 관리한다.

### 주요 기능

* 약관 확인
* 정책 확인

---

# 전체 사용자 업무 흐름

### ① 로그인

서비스 접속
→ 로그인 / 회원가입
→ 로그인

### ② 업무 확인

대시보드
→ 회사 공지 / 팀장 지시사항 확인
→ 오늘 방문 거래처 / CS / 계약 갱신 / 매출 목표 확인
→ 주간 업무 및 일정 확인

### ③ 고객 관리

고객 현황
→ 고객 검색
→ 고객 상세 확인
→ 고객 등록 / 수정

### ④ 일정 및 미팅

캘린더 / 대시보드
→ 일정 확인
→ 일정 상세
→ 미팅 정보 및 AI 브리핑 확인
→ 미팅 진행
→ 일정 종료
→ 업무보고서 작성

### ⑤ 영업 관리

영업 현황
→ 영업 건 확인
→ 영업 현황 등록 / 관리
→ 회사 / 제품 / 파이프라인 / 유입경로 관리

### ⑥ 업무보고

미팅 보고서 작성
→ AI 작성
→ AI 원본 확인
→ 사용자 수정
→ 보고서 제출

일일 업무
→ 주간 업무
→ 월간 업무

### ⑦ 자료 관리

자료실
→ 파일 업로드
→ 상품 또는 딜 연결
→ AI 에이전트 정보 확인
→ 사용자 검토
→ 딜 정보 저장

### ⑧ 매출 분석

대시보드 매출 목표 클릭
→ 매출분석
→ 기간별 / 회사별 / 지역별 / 상품별 매출 확인

### ⑨ CS 관리

고객 불만 관리
→ 불만 등록
→ 원인 파악
→ 처리
→ 처리 완료

# 화면 간 주요 연결 관계

| 시작 화면     | 사용자 행동      | 이동 화면             |
| --------- | ----------- | ----------------- |
| 로그인       | 로그인         | 대시보드              |
| 대시보드      | 매출 목표 클릭    | 매출분석              |
| 대시보드      | 일정 클릭       | 일정 자세히 보기         |
| 대시보드      | CS 대응 요청 클릭 | 고객 불만 관리          |
| 대시보드      | 계약 갱신 클릭    | 계약 관련 리스트         |
| 캘린더       | 일정 클릭       | 일정 자세히 보기         |
| 일정 자세히 보기 | 보고서 작성      | 업무보고서 작성          |
| 고객 현황     | 고객 클릭       | 고객 자세히 보기         |
| 고객 현황     | 고객 등록       | 고객 등록             |
| 고객 불만 관리  | 불만 클릭       | 고객 불만 자세히 보기      |
| 고객 불만 관리  | 불만 등록       | 불만 등록             |
| 영업 현황     | 영업 건 클릭     | 영업 상세/관리          |
| 자료실       | 자료 등록       | 자료실 등록            |
| 자료실 등록    | 딜 연결        | AI 정보 확인 → 딜 저장   |
| 업무보고      | 보고서 작성      | 업무보고서 작성          |
| 업무보고서 작성  | AI 작성       | AI 결과 확인 → 사용자 수정 |
